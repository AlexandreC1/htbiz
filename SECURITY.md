# Security policy

## Supported versions

Security fixes are made on the default branch. Use the latest available app
release and keep dependencies current.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues. Use GitHub's
private vulnerability reporting for this repository. Include the affected
component, steps to reproduce, and impact. Do not include real user data or
active credentials in the report.

Reports are reviewed as soon as practical. We will coordinate a fix and
disclosure with the reporter. Please rotate any credential that may have been
exposed; removing it from the latest commit does not invalidate it.
